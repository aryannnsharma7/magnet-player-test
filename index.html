How to test

  1. 1Paste a magnet URI or choose Try licensed sample.
  2. 2Wait for the torrent metadata and available media files.
  3. 3Select a file. Tap Play if the browser blocks autoplay.

Important limits

This is a browser peer, not a full desktop torrent client. Browsers use WebRTC and cannot connect to ordinary TCP/UDP-only torrent peers.

Privacy & data: Torrent peers may see your IP address. The browser may upload pieces while connected. Stop the torrent when finished and use only content you are authorized to access.

Server usage

The website serves its code; the client device fetches media bytes directly from peers/web seeds. No backend or video storage is included in this test build.
