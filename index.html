Quick workflow

  1. 1Paste a magnet or HTTP(S) media URL; set Auto-detect unless you know the stream type.
  2. 2For a conventional TCP/UDP torrent swarm, optionally run the companion locally in Termux on your own phone and select My phone engine (Termux).
  3. 3Choose a file if prompted. Use the player controls; tap Play once if autoplay is blocked.

Important limits

No player can promise every URL will work. The source must be reachable, peers must have the requested pieces, and the browser must support the media codec. HLS/DASH sources may require CORS headers.

Privacy: torrent peers may see your network IP. Torrent clients can upload pieces while connected. Stop torrents when finished and use authorized content only.

Project architecture

Default path: GitHub Pages serves only static app files; direct playback, controls, HLS/DASH libraries and compatible WebTorrent transfer run in the visitor's browser. The site does not proxy or store video. For swarms that need conventional TCP/UDP peers, each user can optionally run a local Termux engine on their own device. A remote Railway torrent bridge would move work and bandwidth back to the server, so it is intentionally not the default.
